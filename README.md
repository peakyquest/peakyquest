My work on **mobile ground robots** centers on developing robust autonomous navigation systems for indoor and outdoor use. This includes:

- 🧠 Integrated **micro-ROS** on microcontrollers for real-time embedded communication and control.
- 🗺️ Implemented **SLAM** using **Navigation2 (Nav2)** with both 2D LiDAR and depth cameras.
